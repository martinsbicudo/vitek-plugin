# Support

- **Found a bug?** [Open an issue](https://github.com/martinsbicudo/vitek-plugin/issues)
- **Have a suggestion?** [Open a discussion](https://github.com/martinsbicudo/vitek-plugin/discussions)
- **Need help?** Check the [Examples](/examples) and the [Guide](/guide/getting-started). You can also search the docs with Ctrl+K (Cmd+K on Mac).

## Version support

- **Vite:** `^7` is fully supported (CI required). `^6` is best-effort. `^5` is not supported.
- **Node:** We test on Node 20 in CI. Production should run on an active LTS.
