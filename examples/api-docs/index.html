Vitek API Docs Example

This example demonstrates automatic API documentation (REST + WebSockets) with Vitek.

Documentation

  • API docs – REST (Swagger UI) and WebSockets (AsyncAPI) tabs
  • OpenAPI JSON – Raw OpenAPI 3.0 spec
  • AsyncAPI JSON – Raw AsyncAPI 2.x spec

API

Try the endpoints via Swagger UI or directly:

  • GET /api/health
  • GET /api/users/:id
  • POST /api/users
  • GET /api/posts
